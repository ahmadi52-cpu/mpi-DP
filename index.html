Multimedia Pembelajaran Interaktif (MPI)

Selamat datang di aplikasi pembelajaran Dasar-Dasar Program Keahlian Teknik Jaringan Komputer dan Telekomunikasi. Modul ini dirancang khusus untuk siswa Kelas X SMK Negeri 5 Kolaka Utara untuk memahami prinsip dasar transmisi, layanan jaringan, serta analisis keamanan WLAN.

Capaian Pembelajaran

Memahami prinsip dasar sistem transmisi telekomunikasi, layanan jaringan (networking services), serta keamanan jaringan nirkabel (WLAN).

Berpikir Kritis

Menganalisis dan memecahkan masalah (*troubleshooting*) kestabilan internet serta interferensi sinyal Wi-Fi di lingkungan sekolah.

Evaluasi Mandiri

Menguji pemahaman secara kuantitatif melalui 10 kuis interaktif dengan indikator nilai dan sertifikat kelulusan digital.

Modul Materi Pembelajaran

Pilih sub-materi di bawah ini untuk mempelajari prinsip dasar telekomunikasi.

1. Tembaga (Kabel UTP)

Menggunakan pulsa listrik untuk mentransmisikan data. Rentan terhadap Interferensi Elektromagnetik (EMI) dan memiliki keterbatasan jarak maksimum 100 meter.

Kecepatan: Hingga 1 Gbps

2. Serat Optik (Fiber)

Menggunakan cahaya untuk membawa sinyal data melalui serat kaca. Kebal terhadap gangguan EMI dan mampu menjangkau puluhan kilometer tanpa penurunan sinyal signifikan.

Kecepatan: > 10 Gbps

3. Nirkabel (Wireless/WLAN)

Menggunakan gelombang radio (frekuensi 2.4 GHz & 5 GHz). Praktis dan efisien untuk fleksibilitas perangkat mobilitas tinggi, namun dipengaruhi oleh hambatan fisik.

Kecepatan: Beragam (Wi-Fi 4/5/6)

DNS Service

Domain Name System menerjemahkan nama domain yang mudah diingat manusia (seperti smkn5kolut.sch.id) menjadi alamat IP angka (misal 192.168.1.1).

DHCP Service

Dynamic Host Configuration Protocol memberikan Alamat IP, Subnet Mask, dan Gateway secara otomatis kepada setiap komputer klien yang terhubung ke jaringan.

HTTP / HTTPS

Protokol transfer dokumen web. HTTPS melengkapi komunikasi dengan enkripsi SSL/TLS sehingga data terlindungi dari penyadapan.

Standar Protokol Keamanan WLAN

WPA2-PSK (AES)

Standar keamanan umum yang menggunakan enkripsi AES. Cukup aman namun rentan terhadap *offline dictionary attack* jika kata sandi terlalu sederhana.

WPA3-SAE

Generasi terbaru keamanan Wi-Fi menggunakan protokol SAE (Simultaneous Authentication of Equals). Melindungi dari serangan tebak kata sandi secara lebih tangguh.
